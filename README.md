# 2025 ROBOCUP 搬运小车（开源）

2025 年 ROBOCUP 搬运小车项目的完整机械结构模型，由 SolidWorks 设计。本项目开源了小车的全部三维模型，包括整车总装配、全向轮组、悬挂、里程计轮组等，供学习、复现与二次开发使用。

## 项目内容

### 整车

`00_ROBOCUP搬运小车.SLDASM` 为整车主装配文件，查看整车结构请打开该文件。

### 其他格式

- `YDI-D3..长）.STEP`、`装饰件 - 副本.STEP`：通用 STEP 格式模型，可用其他 CAD 软件打开。

## 下载

1. 打开仓库主页：https://github.com/LOFENBVB/robocup-2025-transport-car
2. 点击页面右上角绿色的 **`<> Code`** 按钮
3. 在弹出菜单底部选择 **Download ZIP**

也可以直接通过以下链接下载主分支完整压缩包：

https://github.com/LOFENBVB/robocup-2025-transport-car/archive/refs/heads/main.zip

下载解压后的目录名为 `robocup-2025-transport-car-main`，保持所有文件在同一目录即可用 SolidWorks 打开主装配体。

主文件为 `00_ROBOCUP搬运小车.SLDASM`，文件名前的 `00_` 是为了让它在文件列表中排在最前面，下载后直接打开该文件即可。

## 使用说明

1. 安装 SolidWorks（建议使用较新版本，如 SolidWorks 2024 及以上）打开模型。
2. 将仓库中**所有文件保持在同一目录下**，否则装配体会因找不到零件而报错。
3. 打开 `00_ROBOCUP搬运小车.SLDASM` 查看整车；单独研究某个模块时打开对应的子装配体即可。

## 说明

- 模型中的标准件（螺丝、轴承、铜柱）为 SolidWorks 标准件库或按实物测绘所得，采购时请以实物尺寸为准。
- **装配体中有部分铜柱未画出**，复现或装配时请结合实际情况自行补充，注意核对支撑高度与安装位置。
- 本项目为比赛用车的结构开源，电路原理图、固件与算法代码不包含在本仓库中。
