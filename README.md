# 2025 ROBOCUP 搬运小车（开源）

2025 年 ROBOCUP 搬运小车项目的完整机械结构模型，由 SolidWorks 设计。本项目开源了小车的全部三维模型，包括整车总装配、全向轮组、悬挂、里程计轮组、主控板/PCB 三维模型等，供学习、复现与二次开发使用。

## 项目内容

| 文件 | 说明 |

| `新二代小车装配.SLDASM` | 二代小车结构装配 |
| `全向轮装配.SLDASM` / `全向轮组.SLDASM` | 全向轮组装配 |
| `滚子装配.SLDASM` | 全向轮滚子装配 |

| `Odom1-3.0(1).SLDASM` | 里程计模块装配 |

### 关键零件

- **轮组**：`全向轮 中盖板`、`全向轮外盖板`、`滚子`、`滚子轴`、`小滚子轴承`、`万向轮`
- **悬挂与底盘**：`摆式悬挂`、`亚克力上板`、`新上板`、`新下板`、`电路板亚克力底板`、`主体连接件专利版2`
- **传动与导轨**：`导轨`、`导轨固定`、`滑块`、`二轮轴固定端`、`二轮轴滑轨端`
- **其他**：`电池`、`maixam挡板`、`mxcam按钮`、`转盘支撑`、各类铜柱与标准件

### 其他格式

- `YDI-D3..长）.STEP`、`装饰件 - 副本.STEP`：通用 STEP 格式模型，可用其他 CAD 软件打开。

## 使用说明

1. 安装 SolidWorks（建议使用较新版本，如 SolidWorks 2024 及以上）打开模型。
2. 将仓库中**所有文件保持在同一目录下**，否则装配体会因找不到零件而报错。
3. 打开 `ROBOCUP搬运小车.SLDASM` 查看整车；单独研究某个模块时打开对应的子装配体即可。
4. 部分 PCB 模型（`Board~*.SLDPRT`、`BottomCopper~*.SLDPRT`、`BottomSilkscreen~*.SLDPRT` 等）是由 PCB 设计软件导出的三维模型，文件较多，属于正常现象。

## 说明

- 模型中的标准件（螺丝、轴承、铜柱）为 SolidWorks 标准件库或按实物测绘所得，采购时请以实物尺寸为准。
- 本项目为比赛用车的结构开源，电路原理图、固件与算法代码不包含在本仓库中。
